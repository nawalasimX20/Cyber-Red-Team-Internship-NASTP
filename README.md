# Cyber Red Team Internship — NASTP

This repository documents the hands-on tasks completed during my Cybersecurity
(Red Team) internship at NASTP, covering penetration testing and ethical
hacking fundamentals — from reconnaissance to a full penetration test capstone.

## 🛠️ Lab Environment
- **Attacker Machine:** Kali Linux (VMware)
- **Target Machine:** Ubuntu Server (VMware)
- **Network Mode:** NAT (isolated lab network)

## 📁 Repository Structure

| Folder | Focus Area |
|---|---|
| `Week-01-Reconnaissance-and-Scanning` | Nmap scanning, enumeration, OSINT |
| `Week-02-Active-Directory-and-Web-Exploitation` | AD basics, Burp Suite, OWASP Top 10 |
| `Week-03-Vulnerability-Assessment` | Vulnerability scanning & analysis |
| `Week-04-Web-Application-Exploitation` | Injection, XSS, auth flaws |
| `Week-05-Password-Attacks-and-Privilege-Escalation` | Hydra, John the Ripper, LinPEAS, sudo misconfig exploitation |
| `Week-06-Exploitation-Frameworks-and-Reporting` | Metasploit, BloodHound, CrackMapExec |
| `Capstone-Full-Penetration-Test` | Full scoped pentest + professional report |
| `Mini-Project-OWASP-Juice-Shop-Automation` | Custom Python tool automating OWASP Top 10:2025 testing against Juice Shop |
Each week folder contains:
- `README.md` — write-up of the task, methodology, and findings
- `screenshots/` — evidence of each step

## ⚠️ Disclaimer
All testing shown in this repository was performed exclusively in an isolated,
self-owned virtual lab environment for educational purposes as part of an
authorized internship program. None of these techniques were used against
systems without explicit authorization.
